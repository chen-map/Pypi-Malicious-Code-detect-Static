# Analysis Guidelines

Consider the package MALICIOUS if you observe:
1. **Code Execution Patterns**: bytecode_exec, compile_exec, eval_exec with obfuscated content
2. **Remote Code Execution**: urlretrieve + exec, urlopen + exec, remote payload download
3. **Data Exfiltration**: suspicious network requests to external servers
4. **System Compromise**: process injection, shellcode execution, privilege escalation
5. **Persistence**: autostart mechanisms, registry modification, scheduled tasks
6. **Obfuscation with Suspicious Content**: heavily encoded data combined with exec/compile

Consider the package SUSPICIOUS if you observe:
1. Unusual code patterns but unclear intent
2. Mixed benign and suspicious behaviors
3. Incomplete attack chains or unclear purposes
4. Moderate obfuscation without clear malicious intent

Consider the package BENIGN if you observe:
1. Only normal imports and function calls
2. Standard library usage without suspicious patterns
3. Legitimate package functionality
4. False positive patterns (e.g., base64 encoding for legitimate purposes)

# Key Points
- Focus on the combination of findings, not individual issues
- Consider severity and type of issues together
- Look for attack chains that combine multiple low-risk issues
- bytecode_exec with critical severity is highly suspicious
- Analyze the context: is this obfuscation hiding malicious code?
- If unsure, favor SUSPICIOUS over BENIGN for security-critical findings
